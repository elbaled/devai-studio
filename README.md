# DevAI Studio — AI Website & App Builder

منصة تطوير ويب وتطبيقات متكاملة تعمل بالذكاء الاصطناعي (Gemini API) مع محرر أكواد، معاينة فورية، تصدير واستيراد ZIP، ومدقق أمان Firebase وتكامل GitHub.

## التشغيل المباشر على GitHub Pages
1. ارفع الملفات الأربعة (`index.html`, `style.css`, `app.js`, `README.md`) إلى مستودع GitHub جديد.
2. ادخل إلى **Settings > Pages**.
3. تحت قسم **Branch** اختر `main` ثم اضغط **Save**.
4. افتح رابط موقعك واضغط على أيقونة المفتاح بالأعلى لإدخال مفتاح `Gemini API Key` الخاص بك.
